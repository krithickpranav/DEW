# Deepam Engineering Works (DEW)

Official website for Deepam Engineering Works — container manufacturing, custom lorry cabins, and heavy commercial vehicle bodies in Tiruchengode, Tamil Nadu.

## Features
- **Hero & Precision Steel Intro**: Dynamic intro and counters showcasing manufacturing scale.
- **The DEW Method**: 3-stage process (Material intelligence, Precision fabrication, Built for the road).
- **Product Catalog**: Container solutions (10ft, 20ft, 24ft, 32ft) and aerodynamic/straight lorry cabins with interactive specifications & comparison tool.
- **Interactive Gallery**: Categorized photo gallery with lightbox modal.
- **Multilingual Support**: English, Tamil, and Hindi translations.
- **Quick Inquiries**: WhatsApp floating chat, quick quote modals, and contact form.
- **Certifications**: Company overview, quality assurance standards, and credentials.

## Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Animations**: GSAP, Framer Motion
- **Icons**: Lucide React
- **Notifications**: React Hot Toast

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
